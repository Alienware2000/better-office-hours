Orb enters thinking when recording stops; noise/failure recovers to listening. Real mic cadence and hands-free interruption remain follow-ups.

Current stress-test repair is on `lane/voice-stress-fixes`. The custom STT/Grok/TTS loop remains, with no new SDK or dependencies. Attachments and settled ink only update context; `sendEvent` keeps its readiness callback signature but intentionally starts no model turn. A live prompt-only upload probe still selected problem one, so this is enforced in the client rather than entrusted to wording. The student sets the agenda by voice.

The microphone remains active with browser echo cancellation during playback. Playback interruption requires about 180ms of stronger microphone activity; ordinary speech uses a lower threshold. The endpoint waits 1.8s of quiet, with an orb tap to submit a meaningful recording immediately. An idle tap pauses; a playing/thinking tap cancels. Beginning board ink cancels speech and motion without submitting a turn. Real speakers, headphones, quiet voices, and noise still need human testing; this is an amplitude-based prototype, not semantic turn detection.

All generated speech is queued, with no hidden three-chunk/70-word cutoff. Upcoming audio is prepared while the current chunk plays. Captions and assistant history advance at sentence playback start, so cancelled future sentences never become conversation history. The currently interrupted sentence can still be partially spoken; there is no word-alignment service. Decimal boundaries are preserved during streaming. API requests and queued visuals are cancelled with the turn. TTS-only notation expansion lives in `lib/agent/spoken-text.ts`, preserving symbols in captions and board data. General repetition reduction is a runtime instruction, not proof of human-sounding delivery.

Fast model stays `grok-4.20-0309-non-reasoning`; reasoning stays `grok-4.6`. JSON tags are never sent to TTS. Active session history is sent each turn, and only the latest four lines are shown as captions. Explicit topic-switch language opens the concept desk. The tutor sees current PDF and board snapshots on the next voice turn, including student marks.

Two lanes live in `lib/agent/grok.ts`: `GROK_MODEL` (fast, non-reasoning, every turn) and `GROK_DEEP_MODEL` (`grok-4.6`, `reasoning_effort: "low"`, `max_tokens` 2400 because reasoning tokens count against the cap and a tight one returns an empty message). The route takes `deep: boolean`. The lane instruction must stay last in the system message; from higher up the fast lane ignored it and answered hard problems itself, and a vague version of the instruction did not work either, so `WHEN_TO_THINK` names the trigger cases and shows an example lead-in. All spoken chunks go through one queue (`enqueueSpeechTask`), because the lead-in and the reasoning reply are produced concurrently and would otherwise play over each other. The client no longer caps spoken output. Shortness belongs in the tutor instructions; the previous cap silently lost closing questions.

Captions are in `app/(session)/voice/Captions.tsx`, deliberately not `components/transcript/`, which belongs to the shell lane. Do not move or replace these components without a coordinated PR with David. `useVoiceLoop` returns `turns: Turn[]` and revises the last tutor line as the reply streams. The panel only shows the last four spoken lines, unselectable, so it reads as live captions instead of a chat you scroll and highlight. Putting the paper away (`putAwayPset`) clears the homework history the model was using, not just the on-screen lines.

Leave parks a **session**, not just a view. There are three kinds: lobby (the orb waiting room), homework (this pset), and concept. `exitWorkspace` snapshots homework/concept history and captions, then resets to the greeting so lobby talk cannot keep asking about the PDF. `enterWorkspace` and saying homework restore the parked homework session. `putAwayPset` throws the paper away instead of parking it. "Explain a concept" from the lobby does not keep the pset transcript or `livePage`. Bracket-only STT (`[background noise]`) is dropped in `speech.ts` before it becomes a turn.

## workspace
Stress-test follow-up: PDF navigation scrolls the desk container to reveal the pointed or highlighted region only when offscreen, instead of centering the whole page or moving the document body. Coordinates use measured page rectangles after zoom, and the pointer continues to track scrolling. Caption autoscroll stays inside its own panel. Model localization accuracy and cursor aesthetics still need human review.

On `lane/workspace`, branched from `lane/voice`. Drop zone after Homework / `[MODE pset]`. Upload is `POST /api/pset/upload`, files in `.data/psets` (gitignored). Viewer is PDF.js in the browser. Pointer eases; tutor highlight is a marker; student ink is freehand. Current page JPEG (max 1024px) is posted with the LLM turn so Grok can emit `[POINT]`. The tutor's pointer is `components/workspace/Pointer.tsx`: the head eases toward the target on every frame and drags a fading tail, drawn as separate segments in pixel space. Do not go back to a gradient-stroked path, which fades along the page's x axis rather than the direction of travel, and do not go back to a CSS position transition, which teleports. The highlight is a marker stroke that sweeps left to right under `mix-blend-mode: multiply`, keyed on the bbox so a new highlight replays the sweep instead of sliding. Both honor `prefers-reduced-motion`.

The visible page now drives `livePage` through an IntersectionObserver, so the tutor sees whatever the student scrolled to. It used to update only when the tutor pointed, which left it blind to scrolling. The pset is held by `VoiceSession`, not `WorkspacePane`. Leave parks the desk instead of unmounting it, so the PDF, scroll, and ink are still there on return. A parked desk passes `active={false}` so it stops publishing `livePage`; otherwise Grok kept seeing the pset from the lobby. The Homework chip restores a parked desk without sending another utterance. `Leave` is on the workspace bar; Escape does the same. Do not overlay the welcome stage on top of an open desk: that trapped clicks on Next and Leave. The welcome stage unmounts when the split is open. The laser is one overlay on the visible page frame, not a per-page mount, so it can travel between problems. The first point arrives from slightly below the target; later points continue from the last head, including across remounts. The tutor highlight is an irregular marker stroke (`Overlay` `Marker`) with a left-to-right sweep and multiply blend, keyed on the bbox so a new region replays the sweep.

Student ink is the second bar: hand, pen, highlighter, eraser, and black / rust / gold (`InkBar`). Zoom and page stepping sit in the same pill. Default 100% fits the desk column on every viewport; − / + zoom around the center of the desk, pinch or Ctrl-scroll zoom around the cursor, and the hand tool drags to pan. Click the percent to fit again. Range is 75% to 250%. Do not scale the page width without pan: that cropped the paper. Default tool is hand so the page still moves. Strokes stay in the viewer and are composited onto the vision JPEG (`paintInkOnImage`). Do not send freehand ink through `StudentAnnotation` in `lib/types.ts`. Drag-to-circle / underline is gone; it felt unlike a notebook. **Remove** on the title bar puts the PDF away and starts a fresh homework session (drop zone, empty captions). This is not a notebook library. Two CSS-only transition attempts felt janky in human review; replaced them with Motion `layoutId` for the orb and independent workspace entry. Do not restore the old transform/width choreography. Missing-key mode still opens Homework without calling the agent. Breakpoints: workspace-heavy split on desktop, stacked agent/workspace at 640px. The ink bar sizes down with the desk via a container query. Dedicated mobile design is later.
