# Build notes

Each lane keeps a few lines here: what works, what is stubbed, what other lanes need to know.

## voice
Base is on `lane/voice`; the current safety pass is uncommitted on `lane/workspace`. Own loop: ElevenLabs STT, Grok (`grok-4.6` via `/api/agent/llm`), ElevenLabs TTS. Voice starts paused and the black orb is the pause/resume control. Page hide, another active tab, or orb pause cancels requests, queued speech, audio, recording, and mic input. Mic tracks are disabled during tutor audio and for a 450ms cooldown. Acoustic barge-in is intentionally removed from the RMS loop; use the orb until ElevenLabs Conversational AI SDK turn handling is wired. Flash TTS receives sentence chunks with `previous_text`; output is capped at two chunks and 70 words. Current voice is Jessica (`cgSgspJ2msm6clMCkdW9`), pending human preference review. Model is `GROK_MODEL` in `lib/agent/grok.ts`, now `grok-4.20-0309-non-reasoning` (0.6s to first token through the route, versus 26s on `grok-4.6`). Do not put a reasoning model back on the spoken turn. `lib/agent/context.ts` no longer ships a demo course or pset; it reports only what is loaded and appends a `<no_context_yet>` block that tells the tutor to ask for the upload instead of naming an assignment. `LivePage` now carries `title` and `pages`, supplied by `PdfViewer`. `lib/agent/intent.ts` switches the layout from the student's own words, so saying "my physics homework" opens the pset workspace without touching a chip; the model's `[MODE ...]` tag still applies but is not relied on, because the non-reasoning model often omits it. `lib/agent/events.ts` carries workspace events to the tutor: the client sends only an allowlisted `kind`, never prose, and `PdfViewer` fires `pset_ready` after the first page is rasterized so the tutor can actually read the page before it speaks. The page image now rides as a trailing user message rather than being attached to the last student turn, since an event turn has no student turn. `buildVoiceNote` bans the tutor's stock openers plus its own last four openings; a plain "vary your phrasing" instruction was ignored and it opened three sessions in a row with "Got it, physics homework". Temperature is 0.85. The greeting is one of four fixed lines picked per session, kept as fixed text so the first word is instant. Chips inject as utterances. Tag parser lives in `lib/agent/tags.ts`; UI commands are not dispatched yet. Needs `.env.local` with `XAI_API_KEY` and `ELEVENLABS_API_KEY`. `node scripts/check-turns.mjs` replays a greeting turn, a repeat turn, the `pset_ready` event, and a question against a page, printing first-token latency and the spoken text, so voice behavior can be checked without a mic.

Two lanes live in `lib/agent/grok.ts`: `GROK_MODEL` (fast, non-reasoning, every turn) and `GROK_DEEP_MODEL` (`grok-4.6`, `reasoning_effort: "low"`, `max_tokens` 1400 because reasoning tokens count against the cap and a tight one returns an empty message). The route takes `deep: boolean`. The lane instruction must stay last in the system message; from higher up the fast lane ignored it and answered hard problems itself, and a vague version of the instruction did not work either, so `WHEN_TO_THINK` names the trigger cases and shows an example lead-in. All spoken chunks go through one queue (`enqueueSpeechTask`), because the lead-in and the reasoning reply are produced concurrently and would otherwise play over each other. Speech caps stop the next sentence rather than trimming the current one; trimming cut the tutor's closing question mid-word.

Captions are in `app/(session)/voice/Captions.tsx`, deliberately not `components/transcript/`, which belongs to the shell lane. If the shell lane builds the real transcript, move this and delete it here. `useVoiceLoop` returns `turns: Turn[]` and revises the last tutor line as the reply streams.

Open pedagogy risk with the non-reasoning model: on a page question it said "First thing is to split the launch velocity into x and y pieces" and then asked "What do you think the first step is?", which is rung 3 of the hint ladder followed by rung 1. PROMPT.md says never open at the bottom. This is the tradeoff for sub-second speech and is why the reasoning-lane split matters. It also invented a table on a cliff problem. Anything that needs to be right about the work should go through `[THINK]`.

## workspace

Missing-key mode still opens Homework without calling the agent. Breakpoints: 58/42 at 900px, stacked agent/workspace at 640px. Dedicated mobile design is later.
