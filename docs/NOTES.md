## workspace
On `lane/workspace`, branched from `lane/voice`. Drop zone after Homework / `[MODE pset]`. Upload is `POST /api/pset/upload`, files in `.data/psets` (gitignored). Viewer is PDF.js in the browser. Pointer eases; tutor highlight is a marker; student ink is freehand. Current page JPEG (max 1024px) is posted with the LLM turn so Grok can emit `[POINT]`. The tutor's pointer is `components/workspace/Pointer.tsx`: the head eases toward the target on every frame and drags a fading tail, drawn as separate segments in pixel space. Do not go back to a gradient-stroked path, which fades along the page's x axis rather than the direction of travel, and do not go back to a CSS position transition, which teleports. The highlight is a marker stroke that sweeps left to right under `mix-blend-mode: multiply`, keyed on the bbox so a new highlight replays the sweep instead of sliding. Both honor `prefers-reduced-motion`.

The visible page now drives `livePage` through an IntersectionObserver, so the tutor sees whatever the student scrolled to. It used to update only when the tutor pointed, which left it blind to scrolling. The pset is held by `VoiceSession`, not `WorkspacePane`. Leave parks the desk instead of unmounting it, so the PDF, scroll, and ink are still there on return. A parked desk passes `active={false}` so it stops publishing `livePage`; otherwise Grok kept seeing the pset from the lobby. The Homework chip restores a parked desk without sending another utterance. `Leave` is on the workspace bar; Escape does the same. Do not overlay the welcome stage on top of an open desk: that trapped clicks on Next and Leave. The welcome stage unmounts when the split is open. The laser is one overlay on the visible page frame, not a per-page mount, so it can travel between problems. The first point arrives from slightly below the target; later points continue from the last head, including across remounts. The tutor highlight is an irregular marker stroke (`Overlay` `Marker`) with a left-to-right sweep and multiply blend, keyed on the bbox so a new region replays the sweep.

Student ink is the second bar: hand, pen, highlighter, eraser, and black / rust / gold (`InkBar`). Zoom and page stepping sit in the same pill. Default 100% fits the desk column on every viewport; − / + zoom around the center of the desk, pinch or Ctrl-scroll zoom around the cursor, and the hand tool drags to pan. Click the percent to fit again. Range is 75% to 250%. Do not scale the page width without pan: that cropped the paper. Default tool is hand so the page still moves. Strokes stay in the viewer and are composited onto the vision JPEG (`paintInkOnImage`). Do not send freehand ink through `StudentAnnotation` in `lib/types.ts`. Drag-to-circle / underline is gone; it felt unlike a notebook. **Remove** on the title bar puts the PDF away and starts a fresh homework session (drop zone, empty captions). This is not a notebook library. Two CSS-only transition attempts felt janky in human review; replaced them with Motion `layoutId` for the orb and independent workspace entry. Do not restore the old transform/width choreography. Missing-key mode still opens Homework without calling the agent. Breakpoints: workspace-heavy split on desktop, stacked agent/workspace at 640px. The ink bar sizes down with the desk via a container query. Dedicated mobile design is later.
